# Project instructions

- This repository is a specification-driven project initializer and must remain free of generated application code.
- `SPEC.md` is the source of truth for the foundation generated in a target repository. `README.md` contains the user-facing initialization workflow.
- Update `SPEC.md` first when changing the supported foundation; keep the README and this file aligned where needed.
- Keep the starter product-neutral. Do not introduce domain-specific assumptions or infrastructure until it becomes part of the intentionally supported baseline.
- Preserve pragmatic TDD guidance and strict test database isolation requirements in `SPEC.md`.
- Generated projects may evolve independently after initialization.
- Keep repository content in English. Avoid destructive Git operations and do not push unless explicitly requested.
